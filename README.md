## 数据集概述

本数据集专注于**园林与古典建筑元素的视觉检测与识别**，服务于古建筑保护、园林景观研究及建筑遗产数字化。数据涵盖八类典型园林建筑构件与景观元素，适配古建普查、园林规划及自动化建筑识别等应用。

## 数据三要素解析

**类别与建筑元素覆盖**
*   数据集定义 **8** 类园林建筑元素，覆盖 **建筑构件类**（门、墙、廊）、**景观元素类**（桥、石、亭）及 **大型建筑类**（塔、宫殿）。
*   类别设置覆盖了中国古典园林与建筑的主要元素类型，具有较强的专业性与系统性。
*   类别命名简洁明确，便于模型学习与结果解读。

**数据规模与版本**
*   图像总量约 **2272** 张，规模适中，能支撑多类别建筑元素检测模型的训练。
*   数据集有 **1** 个版本，数据已整理完毕，可直接使用。
*   图像涵盖不同季节、光照条件下的园林建筑场景。

**格式与结构**
*   采用通用 **YOLO 格式**（txt），每张图像对应一个同名标签文件，包含类别 ID 与归一化边界框坐标，可直接接入 YOLOv5、YOLOv8 等主流检测框架。
*   图像与标签一一对应，数据结构规范，便于进行训练/验证集划分与预处理集成。

## 知识普及：园林建筑检测的技术要点

*   **建筑形态多样**：从简单的门、墙到复杂的宫殿、塔，建筑元素在形态、尺度上差异显著，需模型具备多类别特征提取能力。
*   **背景复杂性**：园林场景包含植被、水面、山石等背景，建筑元素可能与背景混淆，模型需依赖形态与纹理特征进行区分。
*   **尺度变化**：建筑元素在图像中的尺寸受拍摄距离与角度影响显著，需采用多尺度训练策略。
*   **光照与季节影响**：户外拍摄受光照、季节影响大，建议训练时加入亮度、对比度增强。
*   **应用闭环**：检测结果可导入古建筑BIM系统，用于建筑元素编目、状态评估与修缮规划，服务于建筑遗产的数字化保护。

## 快速开始（代码示例）

配置文件 `data.yaml` 示例：
```yaml
train: ./dataset/images/train
val: ./dataset/images/val
nc: 8
names: ['门', '墙', '桥', '石', '塔', '廊', '宫殿', '亭']
```

启动 YOLOv8 训练：
```python
from ultralytics import YOLO

model = YOLO('yolov8m.pt')
model.train(
    data='data.yaml',
    epochs=100,
    imgsz=640,
    batch=16,
    device=0
)
```
